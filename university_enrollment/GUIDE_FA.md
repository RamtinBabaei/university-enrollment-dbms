# راهنمای پروژه: سامانه مدیریت ثبت‌نام دانشگاه

## ایده و کاربرد

این پروژه اطلاعات دانشجویان، درس‌ها، گروه‌های ارائه‌شده و ثبت‌نام‌ها را در پایگاه داده ذخیره می‌کند. کاربر از **پنل مرورگر** دانشجو و درس ایجاد می‌کند، برای هر درس در یک ترم گروه با ظرفیت معین تعریف می‌کند، دانشجو را ثبت‌نام یا منصرف می‌کند، نمره ثبت می‌کند و کارنامه و میانگین وزنی می‌گیرد. رابط خط فرمان نیز برای اجرای دستورها و مشاهدهٔ خروجی JSON در دسترس است.

در عنوان «Database Management System» منظور یک **برنامهٔ کاربردی مبتنی بر پایگاه داده** است. خود موتور دیتابیس از ابتدا نوشته نشده است؛ SQLite موتور ذخیره‌سازی است، SQL ساختار و پرس‌وجوها را تعریف می‌کند و Python منطق برنامه را اجرا می‌کند.

## چرا چهار جدول؟

| جدول | داده‌ها | ارتباط |
| --- | --- | --- |
| `students` | شماره، نام، ایمیل | هر دانشجو می‌تواند چند ثبت‌نام داشته باشد. |
| `courses` | کد، نام، تعداد واحد | هر درس می‌تواند در چند ترم یا گروه ارائه شود. |
| `sections` | ترم، شماره گروه، استاد، ظرفیت | هر گروه به یک درس تعلق دارد. |
| `enrollments` | دانشجو، گروه، وضعیت، نمره | رابطهٔ چندبه‌چند دانشجو و گروه را ثبت می‌کند. |

کلید اصلی (`PRIMARY KEY`) هر ردیف را مشخص می‌کند. کلید خارجی (`FOREIGN KEY`) ارتباط جدول‌ها را سالم نگه می‌دارد. محدودیت `UNIQUE` از شماره دانشجویی، ایمیل، کد درس و ثبت‌نام تکراری جلوگیری می‌کند. `CHECK` بازهٔ ظرفیت، تعداد واحد و نمره را کنترل می‌کند.

## اجرای پنل در Windows

فایل ZIP را استخراج کنید، PowerShell را در پوشهٔ `university_enrollment` باز کنید و بزنید:

```powershell
python web.py
```

برنامه خودش یک پورت آزاد انتخاب و مرورگر پیش‌فرض را باز می‌کند. اگر مرورگر خودکار باز نشد، **دقیقاً همان آدرسی را که بعد از `OPEN THIS ADDRESS` در PowerShell چاپ شده** در Chrome وارد کنید؛ آدرس اجرای قبلی ممکن است دیگر درست نباشد. تا زمانی که پنجرهٔ PowerShell باز است، پنل کار می‌کند. برای توقف `Ctrl+C` بزنید. بانک نمونهٔ `university.db` داخل بسته است؛ بنابراین بلافاصله اطلاعات دو دانشجو، دو درس و دو گروه را می‌بینید. از منوی کناری می‌توانید فرم‌های افزودن و ویرایش دانشجو/درس، ساخت گروه، ثبت‌نام، نمره، انصراف و کارنامه را امتحان کنید.

برای بانک کاملاً جداگانه و خالی: `python web.py --db fresh.db`؛ برای ایجاد بانک جداگانه با دادهٔ نمونه، ابتدا `python app.py --db fresh.db seed` را اجرا کنید و سپس `python web.py --db fresh.db` را بزنید.

اگر صفحه در Chrome سفید بود، پنجرهٔ سرور قبلی را ببندید و `python web.py` را دوباره اجرا کنید؛ آدرس تازهٔ چاپ‌شده را باز کنید. اگر مشکل ماند، متن کامل PowerShell، آدرس Chrome و عکس صفحه را برای بررسی بفرستید. خطاهای مربوط به بانک اکنون در خود صفحه نیز نشان داده می‌شوند.

## اجرای خط فرمان (اختیاری)

نیازمندی: Python نسخهٔ 3.10 یا جدیدتر. برنامه به بستهٔ اضافی نیاز ندارد. در Windows اگر دستور `python` کار نکرد، از `py` استفاده کنید.

```bash
python app.py students
python app.py sections
python app.py transcript S1001
python -m unittest -v
```

بانک `university.db` همراه بسته و دارای دادهٔ تمرینی است. برای ساخت بانک **جداگانه** با دادهٔ نمونه از `python app.py --db fresh.db seed` و برای شروع بانک جداگانهٔ خالی از `python app.py --db fresh.db init` استفاده کنید. اجرای دوبارهٔ `seed` روی بانک دارای داده خطا می‌دهد. همهٔ فرمان‌ها با `python app.py --help` قابل مشاهده‌اند.

برای تجربهٔ کامل با بانک نمونهٔ داخل بسته این دستورها را اجرا کنید:

```bash
python app.py add-student S1003 "Sara Ahmadi" sara@example.com
python app.py add-course CS303 "Human Computer Interaction" 3
python app.py add-section CS303 2026-Fall 1 "Dr. Example" 25
python app.py enroll S1003 3
python app.py grade S1003 3 87.5
python app.py transcript S1003
python app.py drop S1003 3
```

عدد `3` در این مثال شناسهٔ گروه جدید در بانک نمونه است؛ اگر داده‌های خودتان را دارید، شناسهٔ چاپ‌شده توسط `add-section` را جایگزین کنید. برای پاک‌کردن کامل داده‌های نمونه می‌توانید فایل `university.db` را حذف و بانک تازه ایجاد کنید.

## منطق و نکات فنی مهم

1. ظرفیت گروه فقط تعداد ثبت‌نام‌های فعال را می‌شمارد. انصراف ظرفیت را آزاد می‌کند و سابقهٔ ردیف حفظ می‌شود.
2. بررسی ظرفیت و ثبت‌نام در یک تراکنش `BEGIN IMMEDIATE` انجام می‌شود تا دو درخواست هم‌زمان نتوانند بیش از ظرفیت دانشجو اضافه کنند.
3. ثبت‌نام تکراری در یک گروه و ثبت‌نام هم‌زمان در دو گروه از یک درس در یک ترم رد می‌شود.
4. نمره باید بین صفر و ۱۰۰ باشد. میانگین گزارش برابر است با مجموع «نمره × واحد» تقسیم بر مجموع واحدهای درس‌های نمره‌دار. این عدد معدل مقیاس ۴ نیست.
5. پرس‌وجوها پارامتری هستند (`?`) تا ورودی کاربر به متن SQL چسبانده نشود.
6. حذف دانشجو یا درسی که رکورد وابسته دارد با کلید خارجی متوقف می‌شود؛ این طراحی از حذف تصادفی سابقه جلوگیری می‌کند.

## برای توضیح در مصاحبه یا ارائه

ابتدا پنل مرورگر و مسئلهٔ ثبت‌نام را نشان دهید؛ سپس چهار جدول و رابطهٔ `courses → sections → enrollments ← students` را توضیح دهید. یک ثبت‌نام و کنترل ظرفیت را نمایش دهید، نمره وارد کنید و کارنامه را باز کنید. پس از آن تراکنش SQL و آزمون‌ها را شرح دهید. هنگام افزودن پروژه به رزومه، فقط امکاناتی را ادعا کنید که اجرا و منطق آن‌ها را خودتان بررسی کرده‌اید.

محدودهٔ نسخهٔ فعلی: پنل فقط روی کامپیوتر خودتان اجرا می‌شود و ورود کاربران، بررسی تداخل ساعت کلاس‌ها و پیش‌نیاز درس‌ها ندارد. افزودن API، کنترل دسترسی و PostgreSQL می‌تواند مرحلهٔ بعدی باشد.
